Fitur Utama

Tambah Produk: Memasukkan data produk baru ke dalam basis data lokal.
Edit Produk: Memperbarui informasi produk yang sudah ada.
Hapus Produk: Menghapus data produk yang sudah tidak diperlukan dari basis data.

Prasyarat Sistem

Java Development Kit (JDK) versi 17 atau lebih baru
Apache Maven
Apache NetBeans IDE (opsional, disarankan untuk kemudahan menjalankan proyek)

Cara Menjalankan Aplikasi

Buka proyek `KatalogProduk` melalui Apache NetBeans IDE (`File > Open Project`).
Pastikan perangkat terhubung ke internet saat pertama kali menjalankan proyek agar Maven dapat mengunduh seluruh dependensi JavaFX dan SQLite JDBC secara otomatis.
Klik kanan pada proyek `KatalogProduk`, pilih Run Maven > Goals..., ketik `javafx:run`, lalu klik OK.
